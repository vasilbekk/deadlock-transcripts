# Deadlock Transcripts

[English documentation](../../README.md)

Многоязычные транскрибации всех реплик героев Deadlock и готовые Python-инструменты
для транскрибации и перевода.

Более 70 000 транскрипций реплик доступны на английском и русском языках.

[Готовые транскрипции](../../data/transcriptions) лежат в отдельных JSON-файлах по
героям. Поля записи и метаданные текста для каждого языка описаны в
[схеме JSON](./transcription.md#результат).

## Языки

- English (`en`)
- Russian (`ru`)

Новые языки можно добавлять через `deadlock-translate` с локальной моделью Ollama
на своей видеокарте.

## Документация

- [Настройка](./setup.md): Python, FFmpeg, Ollama и команды для разных платформ
- [Транскрибация](./transcription.md): извлечение файлов игры, сборка каталога и
  настройка Whisper
- [Перевод](./translation.md): перевод JSON-файлов героев через Ollama и
  официальные локализации
