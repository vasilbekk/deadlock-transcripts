# Deadlock Transcripts

[🇷🇺 Русская документация](./docs/ru/README.md)

Multilingual transcripts for every Deadlock hero voice line, with ready-to-use
Python tools for transcription and translation.

## Languages

- English (`en`)
- Russian (`ru`)

Use `deadlock-translate` with a local Ollama model to add more languages on your
GPU.

## Documentation

- [Setup](./docs/setup.md): Python, FFmpeg, Ollama, and platform-specific commands
- [Transcription](./docs/transcription.md): extract game assets, build the catalogue,
  and configure Whisper
- [Translation](./docs/translation.md): translate hero JSON files with Ollama and
  official localizations
